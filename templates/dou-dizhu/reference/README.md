# reference/ — 斗地主参考实现

本目录放置一份**开源、MIT 许可**的斗地主规则引擎，作为发给秒哒时的
「牌型判定 + 出牌合法性 + 大小比较」参考底座，用来提升生成稳定性。

## 来源与许可

- **仓库**: [onestraw/doudizhu](https://github.com/onestraw/doudizhu)（⭐225）
- **许可证**: MIT（见本目录 `LICENSE`，Copyright (c) 2018 Larry He）— 允许商用、再分发、衍生
- **抓取日期**: 2026-08-14

## 文件说明

| 文件 | 作用 |
|------|------|
| `engine.py` | 核心：枚举 37 种牌型，构建花色无关/顺序无关字典，O(1) 判断出牌是否合法并比较大小 |
| `card.py` | 牌与牌组的表示、发牌 |
| `compat.py` | Py2/3 兼容小工具（`engine.py` 依赖） |
| `engine.md` | 作者对牌型枚举与判定算法的设计文档，讲清了规则判定思路 |
| `LICENSE` | MIT 许可证原文（保留版权声明，合规必需） |

## 为什么选它

- 体量小（引擎核心 ~19KB 单文件），聚焦**规则判定**这一最容易出错的部分
- 有完整的牌型枚举和大小比较逻辑，正是秒哒生成时最需要「抄对」的地方
- MIT 许可，可放心作为参考代码分发

## remix.py 如何使用本目录

`remix.py build-prompt` 会读取本目录下的代码文件（`.py` 等），
作为「参考以下实现」拼进发给秒哒的生成指令。秒哒据此重新生成前端游戏
（语言/UI 按 `spec.md` 要求，不要求与参考代码同语言）。

> 参考代码仅作实现参考，最终由秒哒重新生成；已确认为 MIT 许可，无版权风险。
> `engine.py` 是 Python，而目标游戏是前端 JS/HTML —— 这没问题：我们要秒哒
> 参考的是**规则判定逻辑**，而非直接复用代码。
